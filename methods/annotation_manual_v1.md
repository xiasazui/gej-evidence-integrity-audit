## 1. 通用规则

### 1.1 标签定义

- `NA`：不适用/未触发（例如病例与 GEJ/贲门恶性线索无关；或该规则的触发条件不满足）。
- `PASS`：触发且证据链完整/一致。
- `FAIL`：触发且存在证据缺失/矛盾/不一致，达到规则定义的 FAIL 口径。

### 1.2 证据锚点（evidence span）

- 仅为 `FAIL` 标注 evidence（建议 1–3 条）。
- evidence 必须可在原文中逐字定位（优先整句或包含关键字段的短片段）。
- 若“缺失型 FAIL”在原文中无法直接定位（因为就是缺失），可提供触发依据的证据（例如诊断行/定位描述行），并在备注中说明“缺失项是什么”。

### 1.3 冻结标签与一致性复核

- `labels_final.jsonl` 保存主标注与争议复核后形成的冻结 final labels。
- 为评估标签可靠性，在主冻结标签完成后，由第二标注者对 140 例子集独立复标；论文报告 final labels 与第二标注结果之间的 Cohen’s kappa 与 agreement rate。
- 该 140 例一致性分析中的分歧保留为可靠性评估结果，不在计算 kappa 前再次调和。
- 一致性复核的目标是检验冻结规则口径的可复标性，而不是重新生成一个经二次调和后的替代 gold set。

### 1.4 冻结版标签文件说明

- 本轮论文冻结版 `data/gold/labels/labels_final.jsonl` 仅保存 adjudicated `PASS/FAIL/NA` 状态，作为定量评测与可视化脚本的统一输入。
- evidence anchors 在标注、仲裁与定性复核中使用，但不要求全部写入冻结版最小标签文件。
- 若后续需要共享 richer schema（例如 `status + evidence + adjudication_note`），应作为并行扩展文件发布，而不是直接改变冻结版主评测文件结构。

## 2. 规则口径（H1–H6）

> 以下为标注口径摘要；论文 Methods 应报告上方 source hash。若文字摘要和代码实现出现差异，以冻结评测时使用的 `gej_audit/llm_rule_pipeline.py` 与 `labels_final.jsonl` 为准，并在返修说明中显式记录。

### H1 组织学证据

- 触发：出现 GEJ/贲门相关恶性肿瘤确诊性表述。
- FAIL：缺少病理/活检 + 组织学类型关键词（腺癌/鳞癌/印戒细胞癌/神经内分泌癌等）。
- 常见证据位置：现病史/辅助检查/外院病理粘贴段。

### H2 内镜所见证据

- 触发：同 H1。
- FAIL：仅写“做过胃镜/已行胃镜”但无所见（部位/形态/距离等要点）。
- PASS（冻结版边界说明）：若原文明确出现内镜来源的诊断性结论并包含疾病/部位信息（例如“胃镜提示贲门癌”），在本轮冻结 gold labels 中按最低可接受内镜证据处理。更完整的内镜所见（距门齿/切牙距离、EGJ 位置、病变形态、狭窄/出血等）仍然更优，但不是 H2 的冻结版 PASS 必需条件。
- FAIL：仅出现“做过胃镜/已行胃镜”等流程性表述，或仅有无法定位到 GEJ/贲门恶性病变的模糊内镜提及，且未提供可复核所见或诊断性结论。
- 备注：若原文明确写“已行胃镜检查，但病历未记录任何所见/结果细节”，仍按 FAIL 处理。

### H3 远处转移-诊断一致性

- 触发：出现远处转移或 M1/IV期/晚期 等线索（注意与区域淋巴结区分）。
- FAIL：触发后诊断未体现转移/分期信息。

### H4 定位证据完整性

- 触发：出现 GEJ/贲门癌/远端食管腺癌/贲门下胃癌 或 Siewert I/II/III 线索。
- FAIL（Critical）：诊断写明 Siewert/亚部位，但缺少 **可复核的 Z线/齿状线相对距离证据**：
  - 肿瘤中心相对 Z线/齿状线距离；或
  - 病变上界/下界相对 Z线/齿状线距离（可替代中心距离）。
- FAIL（Major）：仅诊断为 GEJ，但缺少可复核定位证据（内镜定位/距门齿或切牙距离/Z线或齿状线距离）。
- 不计入定位证据：仅有 CT/PET/MR 等影像学“部位描述”（例如“贲门占位/食管下段增厚”）不作为 H4 的定位证据。

### H5 定位一致性（Siewert/GEJ 阈值）

- 触发：诊断（含 Siewert 或 GEJ）且同时提供 Z线/齿状线距离。
- 若仅提供“上界/下界至 Z线/齿状线距离”而未给出中心距离：本条 NA（不做一致性判定）。
- FAIL：分型范围或 GEJ ±5cm 口径不一致。
- 备注：需在论文中明确 Siewert 分型口径与（如涉及）AJCC 分期归属口径的区别。

### H6 病历要素与命名规范

- 触发：所有病历。
- FAIL（Major）：12 项必备字段缺失任一，或字段名存在但字段值为空（例如“既往史:”冒号后为空）。
  - “非空即可”原则：字段值允许很简略（如“无特殊”“见现病史”“家属咨询”），不因“内容不够详细”判缺失。
- FAIL（Minor）：诊断命名无法规范复核（例如部位不明确且恶性性质不明确）。
  - ICD 不是必需：不要求出现 C15/C16；出现 ICD 也不强制校验正确性。
  - 只要诊断中能明确“部位 + 恶性性质”（如“贲门癌/胃食管结合部腺癌/恶性肿瘤”）即可视为可复核。

## 3. 高风险边界速查表

以下示例为抽象化标注边界说明，用于解释冻结口径；不改变已冻结的 `labels_final.jsonl`。

| 规则 | PASS 边界 | FAIL 边界 | NA 边界 | 标注提醒 |
| --- | --- | --- | --- | --- |
| H2 内镜所见证据 | 有可复核内镜所见，或至少有明确内镜来源诊断性结论，例如“胃镜提示贲门癌”。 | 仅有“已行胃镜”“胃镜检查完成”“建议复查胃镜”等流程性表述，未记录所见或诊断性结论。 | 一般同 H1 触发；若病例本身不触发 GEJ/贲门恶性背景，则 NA。 | H2 不要求完整内镜报告，但要求门诊记录中留下可被 reviewer 复核的内镜证据锚点。 |
| H4 定位证据完整性 | 有距门齿/切牙距离、Z线/齿状线距离、EGJ/贲门交界定位，或病变上/下界相对 Z线/齿状线距离。 | 只有“Siewert II”“GEJ 癌”“贲门癌”等结论性命名，或只有 CT/PET/MR 部位描述，缺少可复核定位依据。 | 未出现 GEJ/贲门/远端食管/贲门下胃/Siewert 等触发线索。 | H4 只审“定位证据是否存在”，不审分型阈值是否一致；不要把 H5 的矛盾归到 H4。 |
| H5 定位阈值一致性 | 有肿瘤中心相对 Z线/齿状线距离，且距离与 Siewert/GEJ 命名不冲突。 | 同一病历内中心距离与 Siewert I/II/III 或 GEJ 命名阈值明确冲突。 | 缺少肿瘤中心距离；仅有上界/下界距离；或不触发 Siewert/GEJ 一致性判断。 | H5 是“已有中心距离后的自洽性判断”；缺距离时不要判 FAIL，缺失由 H4 承担。 |
| H6 病历要素与命名规范 | 12 项必备字段均存在且非空；诊断能明确部位与恶性性质。很简略的非空值如“无特殊”“见现病史”“家属咨询”仍可 PASS。 | 任一必备字段缺失或冒号后为空；诊断名称无法复核部位或恶性性质。 | H6 适用于所有病历，通常不设 NA。 | ICD code 不是必需项；H6 不评价字段内容是否丰富，只评价最小完整性与诊断命名可复核性。 |

## 4. 标注者操作流程

1. 先判断规则是否触发；未触发时标 `NA`，不要将 `NA` 合并为 `PASS`。
2. 触发后判断最小证据链是否满足；满足标 `PASS`，缺失或矛盾标 `FAIL`。
3. 对 `FAIL` 记录 1–3 条证据锚点。若是缺失型 FAIL，锚点可记录触发依据，并在备注中说明缺失项。
4. 对 H2、H4、H5、H6 的边界案例优先参考上表，尤其注意 H4/H5 职责分离和 H6 的“非空即可”原则。
5. 如需后续公开 richer labels，应以并行扩展文件保存 evidence 与 adjudication note，不直接改变冻结定量标签文件结构。
