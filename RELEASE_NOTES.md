# v1.0-submission release notes

This release provides the script-generated synthetic portion of the constructed GEJ evidence-integrity benchmark: 80 synthetic originals, 480 H1-H6 synthetic-derived variants, synthetic-only Gold and lineage, normalized frozen outputs for 11 systems, supporting deterministic code and method files, privacy-minimized aggregate tables, and publication figures.

The archived generator does not read real-record files during execution, and the available provenance does not show case-by-case derivation from the 20 real records. The historical knowledge source of the embedded templates and candidate lists was not contemporaneously documented, so this release does not claim independence from all clinical knowledge or records.

Real and real-derived case text, real-source case-level artifacts, Appendix B, patient/provenance mappings and secrets are excluded.

Licensing: code and Python methods files are released under MIT; synthetic data, frozen outputs, evidence and documentation are released under CC BY 4.0.
